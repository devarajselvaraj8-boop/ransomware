1. EXECUTIVE SUMMARY & INITIAL 100% ACCURACY INVESTIGATION
--------------------------------------------------------------------------------
An initial Random Forest baseline achieved 100% across Accuracy, Precision, Recall,
and F1-Score. In empirical cybersecurity research, perfect classification on dynamic
behavioral datasets is an immediate warning sign requiring critical validation.

Our investigation reveals THREE primary factors contributing to this outcome:
  (A) Sandbox-Wide Post-Execution Aggregations: Features represent whole-execution
      summary counts (e.g. apistats, file_read, file_created, log), capturing the entire
      lifecycle after the ransomware has already executed and encrypted files.
  (B) Strict Redundancies & Duplicate Columns: 15 pairs of feature columns are 100%
      identical (e.g., pe_res_name == filetype, arguments == api == category).
  (C) Distinct Family Profiles: The 3 malware families (E, G, L) exhibit distinct
      distributional clusters in their sandbox logs (e.g., file creation counts and
      API statistics differ by orders of magnitude).

4. FEATURE RETENTION / REMOVAL SCIENTIFIC RATIONALE
--------------------------------------------------------------------------------
Guiding Research Principle:
  Per project instructions, we do NOT remove features merely because they are highly predictive.
  We also preserve all 46 features for the baseline model to benchmark against prior runs.

Retention Decision Table:
  - Retained All 46 Features: Maintained in data/processed/ml_ready_dataset.csv.
  - Removal for Baselines: 0 additional features removed.
  - Scientific Rationale:
      1. The baseline goal is to rigorously reproduce and evaluate tree-based classifiers
         on the standard dataset under strict stratified split conditions.
      2. Removing features selectively would introduce researcher bias unless guided by
         an explicit temporal cutoff.
      3. The redundancy between identical pairs (e.g. pe_res_name and filetype) splits
         tree importance but does not bias accuracy in Random Forest or XGBoost.
      4. In Task 11 ('early_stage_gap.md') and Task 12 ('ppo_design.md'), we document
         how real early-stage detection requires shifting from whole-trace aggregations
         to sequential, time-windowed memory and process snapshots.
